{% comment %} Distintivo de estado: color + ICONO + palabra, nunca color solo. Los tres colores de estado del sistema (--good / --warning / --critical) son verde, ámbar y rojo, y para una parte de la gente esos tres son dos: verde-ámbar y ámbar-rojo se acercan bajo deuteranopía y protanopía. Por eso cada estado tiene además una FORMA distinta —círculo con tilde, triángulo, octógono— y una palabra. Quitando el color, el distintivo se sigue leyendo. Parámetros: estado ok | warning | critical | sin_dato | sin_umbral solo_icono True para las tarjetas compactas del listado, donde no entra la palabra. El texto sigue estando para el lector de pantalla y en el title. {% endcomment %} {% if estado == 'ok' %} Normal {% elif estado == 'warning' %} Advertencia {% elif estado == 'critical' %} Crítico {% elif estado == 'sin_umbral' %} {% comment %} Ni regla ni defecto: el número se muestra, pero nadie puede afirmar que esté bien. {% endcomment %} Sin umbral {% else %} Sin dato {% endif %}
